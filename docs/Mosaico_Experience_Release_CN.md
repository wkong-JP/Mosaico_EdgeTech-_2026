# ESP-MOSAICO 旗舰全能体验固件 (EdgeTech+ 2026) — 中文详细介绍

## 1. 项目简介

本固件专为 2026 日本 EdgeTech+ 展会打造，作为 ESP-MOSAICO V1.2（ESP32-S31）的官方旗舰离线体验固件。
固件充分利用了 ESP32-S31 强大的双核 RISC-V 计算核心与 **16 MB Octal PSRAM（250 MHz 极限频率）**，将离线多模态 AI（离线语音识别 + 摄像头手势追踪）、全功能传感器融合（双磁力计 + IMU）、经典重力迷宫物理引擎及 AMOLED 高清流畅动画融于一体。

固件遵循严格的 **Route B 零无线射频（Zero-RF）** 离线设计规范，完全剥离 Wi-Fi、蓝牙、ESP-NOW 协议栈，杜绝展会现场无线干扰与合规风险，开箱即用。

---

## 2. 核心功能与五大界面

### 界面一：Home 首页看板
- 顶部状态栏：显示系统标题、当前电池精准百分比（基于 80 mAh 实测放电曲线修正）及硬件运行指示。
- 右侧磁吸状态指示：动态监测右侧强磁扩展连接。
- 自动化展览巡航（Attract Mode）：无操作 30 秒后自动在各大界面间循环展示，任意触摸即可秒唤醒交互。

### 界面二：Motion 姿态感知与罗盘
- 融合 BMI270（六轴姿态）与板载双 BMM150 磁力计；
- 3D 俯仰与横滚角度平滑渲染，航向角指南针随设备转动实时指向北极；
- 具备磁场基线动态校准功能：轻触罗盘卡片即可一键扣除机身磁干扰。

### 界面三：Audio & AI 语音交互
- **24 频段动态瀑布图**：利用 16MB PSRAM 开辟环形历史缓存，呈现细腻的霓虹音浪流光；
- **双语离线语音控制**：
  - 默认唤醒词："Hi ESP"（支持日语 "こんにちは ESP"）；
  - 唤醒后 5 秒窗口内可说出 "Home"、"Motion"、"Audio"、"Game"、"Device" 或 "System" 等 58 条中英日指令秒切页面；
  - 针对微弱轻音节与非母语发音做了 G2P 音标补偿，识别率与容错率极高。

### 界面四：Tilt Maze 重力物理迷宫
- 真实物理引擎滚球模拟，支持 Easy / Normal / Hard 三阶迷宫；
- **三重控制方式**：
  1. **Tilt（重力倾斜）**：倾斜板卡，小球随地心引力自然滚动；
  2. **Joystick（摇杆模式）**：插入左侧拓展摇杆子板，通过物理摇杆拨动小球；
  3. **Camera（手势识别模式）**：启用 SC101IOT 摄像头，基于 ESPDet-Pico 深度学习网络，伸出手掌即可隔空控球。
- **手势彗星光晕**：在 16MB PSRAM 中维护光标位移历史，在 30 FPS 下进行连续指数插值补帧，挥动手掌呈现流畅的流光彗星尾迹。

### 界面五：Device Info 硬件看板
- **16 MB PSRAM & Flash 内存图谱**：柱状图直观呈现 16MB Octal PSRAM 和 16MB Flash 的分区架构与实时负载，空闲堆内存高达 6.0 MB+，充分彰显乐鑫硬件的强劲承载力；
- **双拓展槽子板自动探测**：动态识别左/右扩展槽所插接的模块类型与 EEPROM 描述符。

### 彩蛋互动：乐鑫官方 Logo 磁吸秒切
- 将右侧磁吸套件贴合机身时，系统硬件中断以 17ms 极速切换至全屏乐鑫官方品牌标识，同时安全挂起摄像头以保护设备；分离磁铁后秒级复原原页面。

## 3. 屏幕显示与圆角适配

- 屏幕规格：480 × 480 全贴合 AMOLED（CO5300 控制芯片）；
- **四弧角防裁切优化**：顶部栏标题与电池图标均采用 28px 水平安全边距，游戏 HUD 时间与退出键内缩，底部两端 Tab 采用 18px 大倒角，与圆形外壳边缘平滑吻合，杜绝内容裁切。

## 4. 固件安装与烧录

本版本发布为 **完整单镜像文件（Offset 0x0）**，包含了启动引导（Bootloader）、分区表、主应用程序与离线语音模型。

### 固件文件信息：
- 文件名：`esp32s31_mosaico_experience_full_0x0.bin`
- 烧录起始偏移：`0x0`
- 文件大小：9,701,827 字节 (~9.25 MB)
- SHA256 校验码：`2f4bb03080c6ac8268f9fa8cc6acfeedeecf004451da039f598f875a982e17b3`
- MD5 校验码：`0daa34a87efb7375ac80dc1d41b6d4ef`

### 烧录命令行：
```bash
# 1. 硬件操作：按住 BOOT 键 -> 按一下 RESET 键 -> 松开 BOOT 键，使芯片进入 ROM 下载模式
# 2. 终端执行写入（以 460800 波特率烧录）：
esptool --chip esp32s31 -b 460800 write-flash 0x0 esp32s31_mosaico_experience_full_0x0.bin
```
烧录完毕后按一下 RESET 键或重新上电即可启动。
